# CasaOps

O CasaOps é um projeto pessoal para monitorar dispositivos da minha rede doméstica e, futuramente, centralizar algumas automações da casa.

A ideia surgiu da necessidade de acompanhar equipamentos conectados ao Wi-Fi, como lâmpadas e tomadas inteligentes, em um painel acessível pela rede local.

## Planejamento inicial

A primeira versão será desenvolvida por etapas. O foco inicial será:

- criar a estrutura do backend e do frontend;
- disponibilizar um health check da aplicação;
- adicionar autenticação;
- cadastrar dispositivos da rede;
- verificar quais dispositivos estão online;
- apresentar essas informações em um painel web;
- automatizar testes e deploy.

As integrações com SmartThings e Smart Life serão avaliadas depois que essa base estiver funcionando.

## Tecnologias previstas

- NestJS
- React
- SQLite
- Nginx
- GitHub Actions

A aplicação será desenvolvida no computador pessoal e implantada inicialmente em um netbook com Linux. Por causa das limitações desse equipamento, o projeto deve continuar leve e simples de manter.
